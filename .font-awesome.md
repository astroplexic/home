# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Self-hosted web fonts with CSS
- **Version:** 5.15.4 for the bundled icon stylesheet; 7.3.1 Brands for the Venmo icon
- **License:** Free
- **Families:** classic, brands

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

Icons are used in HTML with Font Awesome CSS classes, for example `<i class="fas fa-heart">` and `<i class="fa-brands fa-venmo-v">`.

## Conventions

- Font Awesome assets are stored in `assets/css/` and `assets/webfonts/`.
- The Venmo icon uses the Font Awesome 7.3.1 Brands font while other icons continue to use the bundled Font Awesome 5.15.4 stylesheet and fonts.
